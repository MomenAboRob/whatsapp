# WhatsApp Workspace

تطبيق لإدارة محادثات واتساب ومتابعة المنشنات والمهام.

## التشغيل المحلي

1. ثبّت Node.js ثم نفّذ `npm ci`.
2. انسخ `.env.example` إلى `.env.local` واملأ القيم الخاصة بك.
3. شغّل `npm run dev` وافتح `http://localhost:3006`.

على Windows، يمكنك تشغيل `تشغيل واتساب.bat` من المجلد الرئيسي.

## حفظ البيانات على السيرفر

اضبط `DATA_DIR` على مسار قرص دائم يملكه مستخدم التطبيق، مثل `/var/lib/whatsapp-workspace`، وتأكد أن مستخدم Node يستطيع الكتابة إليه. لا تستخدم قرصًا مؤقتًا يُحذف عند إعادة النشر أو إعادة التشغيل. جميع ملفات التطبيق المتغيرة، ومنها جلسة واتساب والرسائل والوسائط والمهام والقوائم ومركز الملفات، تحفظ تحت هذا المسار. يجب إبقاء نسخة احتياطية دورية من المجلد.

عند نقل بيانات موجودة من جهاز Windows، أوقف التطبيق أولًا، وشغّل `scripts/package-server-data.ps1` لتجهيز أرشيف نقل من مجلدات البيانات. انقل الأرشيف إلى السيرفر، فك ضغطه داخل قيمة `DATA_DIR`، ثم أعد تشغيل التطبيق. لا ترفع الأرشيف أو ملفات `.env` إلى Git؛ يحتوي الأرشيف بيانات جلسة واتساب خاصة.

لا يرفع نشر الكود وحده بيانات المستخدم. بيانات التطبيق والوسائط مستثناة من Git عمدًا.

إضافة المتصفح موجودة في `chrome-extension/`، ويمكن تنزيل نسختها المضغوطة من التطبيق.
